## Objetivo da disciplina

A disciplina aborda conceitos e aplicações atuais de Inteligência Artificial, modelos generativos, engenharia de prompt, programação assistida, automação, desenvolvimento Low Code/No Code, agentes inteligentes e responsabilidade ética. As atividades combinam fundamentos teóricos e experimentação prática, com atenção à revisão humana, aos testes e às limitações das ferramentas.

## Critérios de organização

- Cada unidade possui uma página inicial com objetivo, resumo e links para suas atividades.
- Documentos novos devem utilizar Markdown e a extensão `.md`.
- Os nomes dos arquivos devem ser objetivos, em minúsculas e separados por hífen.
- Projetos colaborativos externos são referenciados, sem duplicar seu código neste repositório.
- Resultados de testes devem distinguir o que foi executado, o que foi confirmado por terceiros e o que ainda está pendente.
