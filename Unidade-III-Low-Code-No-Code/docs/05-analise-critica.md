# 05 — Análise crítica e aprendizados

## Três vantagens

### 1. Agilidade na construção

Ferramentas visuais permitem organizar etapas e integrações com menos programação manual. O apoio de IA também pode acelerar a elaboração e o ajuste de partes do protótipo.

### 2. Visualização da lógica

A automação visual facilita compreender a sequência das etapas, as condições e o caminho percorrido pelas informações.

### 3. Integração de recursos

A combinação de automação, interface e IA demonstra como diferentes ferramentas podem colaborar para resolver um problema delimitado.

## Três limitações

### 1. Dependência de plataformas

O funcionamento pode depender de serviços externos, disponibilidade, credenciais, limites de uso e custos.

### 2. Possibilidade de erro da IA

A IA pode interpretar incorretamente uma solicitação ou sugerir uma prioridade inadequada. A revisão humana continua necessária.

### 3. Segurança e manutenção

Mesmo um protótipo simples exige cuidado com dados, credenciais, validação das entradas e tratamento de falhas.

## Aprendizados

- Low Code e No Code reduzem parte do trabalho manual, mas não eliminam a necessidade de compreender a lógica.
- Vibecode pode acelerar o desenvolvimento, mas o resultado gerado precisa ser revisado.
- Integrações precisam de validação e tratamento de erros.
- A IA deve ser utilizada como apoio, e não como substituta da decisão humana.
- Testes e documentação são necessários para avaliar a qualidade de uma solução.

## Continuidade do trabalho

Essa evolução demonstra que um protótipo inicial pode ser ampliado a partir de novos requisitos e integrações. As funcionalidades adicionais devem ser atribuídas à etapa posterior, preservando a distinção entre o escopo inicial e o sistema evoluído.

## Avaliação geral

A atividade permitiu explorar, de forma prática, o uso de automação visual e IA em um problema de suporte técnico. A principal contribuição acadêmica foi compreender que ferramentas Low Code, No Code e Vibecode aceleram determinadas etapas, mas exigem planejamento, validação, revisão humana e atenção à segurança.
