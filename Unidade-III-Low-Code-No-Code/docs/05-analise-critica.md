# 05 — Análise crítica e aprendizados

## Três vantagens

### 1. Rapidez para construir protótipos

Plataformas visuais como o n8n permitem organizar integrações e regras sem desenvolver toda a infraestrutura manualmente. O apoio de IA também pode acelerar a criação e o ajuste de componentes.

### 2. Visualização do processo

Os workflows tornam etapas, condições e caminhos alternativos mais fáceis de acompanhar. Isso ajuda a compreender como os dados passam de um serviço para outro e onde podem ocorrer falhas.

### 3. Integração de ferramentas

O protótipo conecta formulário web, automação, serviços de IA, planilha e e-mail. Essa integração demonstra como tarefas repetitivas podem ser organizadas em um fluxo único.

## Três limitações

### 1. Dependência de plataformas e APIs

O funcionamento depende de serviços externos, credenciais, disponibilidade, limites de uso e possíveis alterações de preço ou de API.

### 2. Respostas imprecisas da IA

A IA pode classificar incorretamente a urgência ou gerar uma orientação inadequada. Por isso, seus resultados precisam ser tratados como sugestões e revisados por pessoas responsáveis.

### 3. Segurança e manutenção

Webhooks públicos, dados pessoais em planilhas e atualização manual do andamento exigem controles. Um protótipo funcional não significa que a solução esteja pronta para operar em uma organização real.

## Aprendizados

- Low Code e No Code reduzem parte do trabalho de programação, mas não eliminam a necessidade de entender a lógica do sistema.
- Vibecode pode acelerar a implementação, mas o desenvolvedor continua responsável por revisar o código e as configurações geradas.
- Integrações precisam de tratamento de erros e validação de dados.
- Uma resposta gerada por IA não deve ser considerada correta apenas por parecer convincente.
- Segurança e privacidade devem ser planejadas desde o início.
- Documentar limitações e testes pendentes é tão importante quanto apresentar funcionalidades.

## Avaliação geral

O projeto demonstra uma aplicação prática das abordagens estudadas na Unidade III. A combinação de n8n, IA, Google Sheets e uma interface web mostra como diferentes ferramentas podem ser integradas para resolver um problema delimitado.

A principal ressalva é que a documentação disponível não comprova a aprovação de todos os testes. Para uma avaliação completa, é necessário executar novamente os cenários pendentes, registrar evidências e revisar as proteções dos endpoints antes de utilizar dados reais.

## Próximos passos recomendados

1. Executar os cenários pendentes e guardar capturas de tela sem dados pessoais.
2. Confirmar o funcionamento atual dos dois workflows no n8n.
3. Revisar a proteção dos webhooks e permissões da planilha.
4. Registrar a divisão real de responsabilidades do grupo, se houver essa informação.
5. Atualizar este documento caso novos testes ou melhorias sejam realizados.
